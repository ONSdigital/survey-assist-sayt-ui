# Bespoke Autosuggest component

This directory contains a project-owned copy of the ONS Design System autosuggest component macro.

The component was copied from:

```text
src/survey_assist_sayt_ui/templates/components/autosuggest
```

to:

```text
src/survey_assist_sayt_ui/app_templates/components/autosuggest
```

so that the Survey Assist SAYT UI can extend the standard ONS autosuggest behaviour without modifying the fetched ONS Design System templates directly.

## Why this exists

The standard ONS autosuggest component supports suggestions from a static data source.

This project also needs an API-backed autosuggest journey. For example, the business activity page needs to call a local Flask route as the user types, which then proxies the request to the configured SAYT/vector-search API.

The bespoke part of this component is support for an `apiSource` parameter.

## Bespoke `apiSource` support

The custom macro renders additional `data-*` attributes when `apiSource` is provided:

```njk
"apiSource": {
    "url": url_for("main.business_activity_suggestions"),
    "queryParam": "q",
    "minChars": 3,
    "additionalChars": 1,
    "maxWaitMs": 3000
}
```

These values are rendered into the autosuggest markup as attributes such as:

```html
data-autosuggest-api-url="/api/business-activity-suggestions"
data-autosuggest-api-query-param="q"
data-autosuggest-api-min-chars="3"
```

The browser JavaScript in:

```text
frontend/js/remote-autosuggest.js
```

uses these attributes to initialise the API-backed autosuggest behaviour.

The generated browser bundle is served from:

```text
src/survey_assist_sayt_ui/static/js/remote-autosuggest.bundle.js
```

## `externalInitialiser`

API-backed autosuggest pages should set:

```njk
"externalInitialiser": true
```

This prevents the standard ONS JavaScript from automatically initialising the component. The component is instead initialised by the project’s bundled JavaScript so that it can use a custom suggestion function and call the Flask proxy endpoint.

## Important notes

Do not modify the fetched ONS Design System templates directly for project-specific behaviour. Those templates may be regenerated by `make templates` or `scripts/fetch_ons_templates.sh`.

Keep project-specific overrides in `app_templates`.

If `frontend/js/remote-autosuggest.js` is changed, rebuild the bundle from the repository root:

```bash
npm run build:js
```

Then ensure the updated bundle is included in the deployed container image.
